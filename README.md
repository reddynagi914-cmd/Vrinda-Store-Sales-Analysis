# Vrinda Store Sales & Customer Performance Analysis

## Project Overview
This project presents an interactive Power BI dashboard developed to analyze e-commerce sales performance and customer behavior for Vrinda Store.

## Tools Used
- Power BI
- Power Query
- Microsoft Excel

## Key Features
- Monthly sales and order trend analysis
- Customer segmentation by gender and age group
- Order status and fulfillment analysis
- Top-performing states and sales channels
- Interactive slicers for dynamic filtering

## Outcome
The dashboard provides actionable insights to support data-driven decision-making and effective sales performance monitoring.
